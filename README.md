# Anse de panier à trois centres

Le trait d'un arc en anse de panier (porche, baie, cintre) : portée, montée, épaisseur.
La page dessine le tracé à la règle et au compas, les trois centres, l'intrados, l'extrados,
les joints de raccord et les cotes, et enregistre le dessin en PNG ou SVG.

**Essayer :** https://danielou.github.io/anse-de-panier/

Une seule page HTML, sans dépendance : elle marche hors ligne, sur ordinateur comme sur téléphone.
